Code Excerpt

The decision function from packages/shared/src/blend.ts, which blends the scores, applies the overrides and orders the reasons:

export function decide(input: DecisionInput): DecisionOutcome {
  const { thresholds: t } = input;
  let finalScore = blendScores(input.ruleScore, input.mlScore, t);
  const overrides: OverrideCode[] = [];
  if (input.payeeConfirmedFraud) {
    overrides.push("CONFIRMED_FRAUD_PAYEE");
    finalScore = Math.max(finalScore, CONFIRMED_FRAUD_FLOOR);      // 95
  }
  if (input.features.ctx_otp_or_app === 1) {
    overrides.push("OTP_REQUESTED");
    finalScore = Math.max(finalScore, t.highThreshold);             // at least HIGH
  }
  const reasons: Reason[] = [
    ...overrides.map((code) => ({ code, points: 100, vars: {} })),
    ...input.hits.map((h) => ({ code: h.code, points: h.points, vars: h.vars })),
  ];
  if (input.mlScore !== null && input.mlScore >= ML_REASON_MIN_SCORE) {
    reasons.push({ code: "ML_PATTERN", points: Math.round(input.mlScore * t.mlWeight),
                   vars: { mlScore: Math.round(input.mlScore) } });
  }
  return { finalScore, band: bandFor(finalScore, t), blocked: input.payeeConfirmedFraud,
           degraded: input.mlScore === null, overrides, reasons };
}

User Manual

Starting it. Install Docker Desktop and make, then run make demo in the project folder. The first start takes 3 to 6 minutes because the ML container generates the data and trains the model. Then open http://localhost:3000. The API docs are at http://localhost:4000/docs. Other useful commands are make test, make e2e, make loadtest and make reset (which deletes all data).

Demo accounts (password Demo@1234, or use the buttons on the landing page): asha@demo.scamshield.in (user), ravi@demo.scamshield.in (analyst) and admin@demo.scamshield.in (admin). For a quick demo, pay kirana.sharma@okaxis (normal), kyc.update.desk@ybl (2-day-old "KYC desk"), olx.seller.deals@ybl (reported 3 times) or prize.claim.center@paytm (confirmed scam, blocked).

Paying. Go to Send money, enter the UPI ID and look at the recipient card, enter the amount and press Check & pay. A LOW payment goes straight through. For MEDIUM, read the reasons, answer the three questions and press Re-check with my answers, then verify, cancel or continue. For HIGH, the safest option is Cancel and report this account. If you really know the person, wait for the 10-second pause and type their UPI ID again. "Payment stopped" means the account is a confirmed scam. My Safety lists your warnings and reports.

Analysts. Open Alerts. New alerts appear live. Click one to see the scores, reasons, model features and payee history, add a note, and choose Confirm fraud (this blocks the payee for everyone) or Mark safe.

Admins. Use the Simulator to run a scam scenario step by step. Use Rules to change rules and thresholds; the what-if panel shows the effect before you save. Model shows the evaluation and lets you retrain, and Health shows services, latency, ML calls and queues. If a decision says "Checked with safety rules only", the ML service was down; check make ps.
